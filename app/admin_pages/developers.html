ToolNet Drama APIv1base https://api-drama.toolnet.tech

Developer Documentation

Short-drama metadata gateway (ReelShort live). Every response uses the envelope {success, data, error, request_id}. Data carries live:true when it came from upstream just now, live:false when served from the local metadata cache. Video URLs are withheld (video_redacted:true) unless distribution is licensed.

Authentication

Send your customer key on every request. Never share it client-side.

X-API-Key: tn_live_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
curl -H "X-API-Key: $TOOLNET_API_KEY" \
  "https://api-drama.toolnet.tech/v1/reelshort/search?q=altarboy&limit=5"
import httpx
r = httpx.get("https://api-drama.toolnet.tech/v1/reelshort/search",
              params={"q": "altarboy", "limit": 5},
              headers={"X-API-Key": "tn_live_xxxx"})
print(r.json()["data"]["total"])
const r = await fetch("https://api-drama.toolnet.tech/v1/reelshort/search?q=altarboy&limit=5",
  { headers: { "X-API-Key": "tn_live_xxxx" } });
const body = await r.json();
console.log(body.data.total);

GET /v1/reelshort/series/{series_id}

Full series metadata (title, poster, description, chapter count, tags).

curl -H "X-API-Key: $TOOLNET_API_KEY" \
  https://api-drama.toolnet.tech/v1/reelshort/series/6a7619d41dcbbd8e12015bfe
import httpx
r = httpx.get("https://api-drama.toolnet.tech/v1/reelshort/series/6a7619d41dcbbd8e12015bfe",
              headers={"X-API-Key": "tn_live_xxxx"})
print(r.json()["data"]["detail"]["chapter_count"])  # 63
const r = await fetch("https://api-drama.toolnet.tech/v1/reelshort/series/6a7619d41dcbbd8e12015bfe",
  { headers: { "X-API-Key": "tn_live_xxxx" } });
console.log((await r.json()).data.detail.title);  // Altarboy

GET /v1/reelshort/series/{series_id}/episodes/{episode_id}

Live episode data from upstream (Round Robin across provider keys). live:true Sample (video_url shown only when licensed):

curl -H "X-API-Key: $TOOLNET_API_KEY" \
  https://api-drama.toolnet.tech/v1/reelshort/series/6a7619d41dcbbd8e12015bfe/episodes/8giu100fn0
import httpx
r = httpx.get("https://api-drama.toolnet.tech/v1/reelshort/series/6a7619d41dcbbd8e12015bfe/episodes/8giu100fn0",
              headers={"X-API-Key": "tn_live_xxxx"})
ep = r.json()["data"]["episode"]
print(ep["episode"], ep["duration"])  # 11 69
const r = await fetch("https://api-drama.toolnet.tech/v1/reelshort/series/6a7619d41dcbbd8e12015bfe/episodes/8giu100fn0",
  { headers: { "X-API-Key": "tn_live_xxxx" } });
console.log((await r.json()).data.episode.duration);  // 69

Limits & caching

  • Per-key rate limit (default 60 req/min) and daily/monthly quotas set by the administrator.
  • Metadata responses are cached; repeats return cache_hit:true without spending upstream quota.
  • Report your request_id when asking for support.
